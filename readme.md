# Colour Utils

This repo contains a collection of typescript functions for manipulating
colours, primarily with a view to accessibility and WCAG compliance.

Because this is mostly for personal use and reference, and I don't think
there's anything particularly unique about this code, I'm not turning this into
an NPM package or anything at the moment.

## Tests

I've tried to get this repo to 100% test coverage. To run tests:

```zsh
npm install
npm test
```
